# Homebrew Tap

```
brew tap almir/tap https://github.com/davletovalmir/homebrew-tap
brew install --cask almir/tap/pretty-reader
```

Installs [Pretty Reader](https://davletovalmir.github.io/md-reader-releases/) — a fast, beautiful Markdown reader and editor for macOS — plus the `pretty` command line tool.

Previously published as `md-reader`. If you have that installed: `brew uninstall --cask md-reader && brew install --cask almir/tap/pretty-reader`.
